# MOAT Decision Quiz — Free Trial vs Freemium vs Demo

> Template de decisão | MOAT Framework — Wes Bush

## M — Market Strategy

**Dominant?**
- [ ] Faz o job muito melhor E cobra menos?
- [ ] TAM grande para freemium (50M+ usuários potenciais)?
- [ ] Usuários conseguem valor sem hand-holding?
3/3 → **Freemium fortemente indicado**

**Disruptive?**
- [ ] Mercado tem muitos clientes over-served?
- [ ] Produto é versão mais simples e acessível?
- [ ] Onboarding pode ser 100% self-service?
3/3 → **Freemium indicado**

**Differentiated?**
- [ ] Serve um nicho sub-servido?
- [ ] ACV alto o suficiente para sales team?
- [ ] Prospect conseguiria "Aha!" no free trial?
3/3 → **Free Trial ou Demo**

---

## O — Ocean Conditions

- [ ] **Red Ocean** (mercado maduro) → PLG
- [ ] **Blue Ocean** simples com quick TTV → PLG
- [ ] **Blue Ocean** complexo → Demo primeiro

---

## A — Audience

- [ ] **Bottom-up** → Free Trial ou Freemium
- [ ] **Top-down** → Demo ou Free Trial com suporte ativo

---

## T — Time-to-Value

- [ ] Valor em < 10 minutos sozinho? → Freemium ou Free Trial self-service
- [ ] Setup significativo mas alta motivação? → Free Trial com suporte
- [ ] Requer educação do mercado? → Demo

---

## Tabela de Decisão

| Combinação | Modelo |
|---|---|
| Dominant/Disruptive + Red + Bottom-up + TTV rápido | **Freemium** |
| Dominant + Red + Bottom-up + TTV médio | **Free Trial** |
| Differentiated + Red + Bottom-up + TTV médio | **Free Trial** |
| Differentiated + Blue + Top-down | **Demo** |
| Novo mercado complexo | **Demo → Free Trial no futuro** |

---

## Híbridos

- [ ] Empresa estabelecida testando PLG sem risco? → **Lance produto separado**
- [ ] Produto rico em features com valor imediato? → **Freemium + trial de features pagas**
- [ ] Quer capturar quem não converte no trial? → **Trial → Freemium ao expirar**
