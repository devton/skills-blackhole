# ARPU Optimization — Aumentar Average Revenue Per User

> Capítulo 14 | Product-Led Growth — Wes Bush

## Fórmula
```
ARPU = Total MRR / Total Users (pagantes)
```

## Por Que Importa
- Clientes repetidos gastam **67% mais** que novos clientes
- ARPU define quais canais de aquisição são viáveis
- Se ARPU = $20, enterprise sales ($2k/cliente) = 8+ anos para break-even

| ARPU | Canais recomendados |
|---|---|
| Baixo | SEO, viral, product-led |
| Médio | Paid + product-led |
| Alto | Inside sales |
| Muito alto | Enterprise sales |

---

## 5 Táticas para Aumentar ARPU

### 1. Use Value Metrics na Precificação
Preço cresce automaticamente com valor entregue.
→ `value-metrics.md` + `pricing-strategy.md`

### 2. Melhore seus Pricing Tiers
- **Paradox of Choice**: mais opções → análise paralisa → status quo
- Limite para 3 planos ou menos
- Destaque o mais popular
- **Caso real**: Teamwork.com removeu planos desnecessários → **+20% ARPU**

### 3. Aumente seus Preços
- Maioria dos empreendedores subestima elasticidade de demanda
- Inflação simples já justifica aumentos periódicos
- Revise a cada 6–12 meses

### 4. Trate seus Melhores Usuários como Realeza
- 80% da receita vem de 20% dos melhores leads
- Liam Boogar-Azoulay (MadKudu): "Otimizar para todos os usuários é tolice"
- Elimine hurdles que forçam seus melhores leads a se auto-qualificarem
- Crie jornadas personalizadas para high-value accounts

### 5. Upsell e Cross-sell
**Upsell:** add-ons + features pagas + serviços
**Cross-sell:** produtos completamente diferentes
- **Caso real**: HubSpot: Marketing Automation → Sales CRM → Help Desk

---

## Regra de Ouro

> Não engorde a receita com junk food (clientes bad-fit).
> Revenue diversity é saudável: 1 cliente não deve ser % grande do ARR.

---

## Ligação com Churn
Caminho mais rápido para melhorar ARPU = reduzir churn primeiro.
ARPU que cresce com churn alto é ilusório.
